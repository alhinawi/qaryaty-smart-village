
## Automatic sample-order fulfilment (2026-11-07)
Sample orders now contain shop/product IDs and quantities. Advancing an in-progress sample to delivered atomically decrements every explicitly counted line, once by account+sample-order ID. Multiple lines are prevalidated together, so insufficient quantity changes neither inventory nor order state. Status and deduction IDs survive same-tab navigation/reload in session storage. Historical delivered samples never deduct merely by rendering. Unlimited inventory stays unlimited. Cancel before delivery has no deduction to restore and is terminal; delivered sample cannot cancel. This demo chooses deduction at delivery, not both placement and delivery. Real reservation-on-placement/finalize-on-delivery remains a separate server proposal. No real order, stock or review repository writes.
