# Sources checked 2026-11-07
1. Obour daily prices, official market, primary data, http://www.oboormarket.org.eg/Prices_ar.aspx . Claims daily morning-auction updates; fetched page has raw date 5/11/2026, price ranges and units/packaging. High confidence wholesale-source identity (also corroborated by Cairo governorate); freshness date not resolved, no API/license verified.
2. Obour statistics download, official market terms/access notice, http://www.oboormarket.org.eg/download_prices.aspx . Says downloads for researchers/decision makers require subscription application and approved requesting-entity letter. High confidence published access condition; not blanket commercial redistribution permission.
3. Cairo governorate market services, official description, https://cairo.gov.eg/ar/governorate-entities/projects/obour-market/services/ . Explicitly describes daily wholesale prices. High confidence that wholesale is not local shop retail.
4. Agriculture ministry daily crops page, official data portal, https://www.agri.gov.eg/databases/83 . Headers distinguish Obour wholesale and representative national retail sample. Fetch exposed headers but no populated price rows. High confidence field semantics; current usable feed unverified.
5. Local/international prices portal, official portal page, http://www.agriprice.gov.eg/local-prices/1 . Fetch exposed title only. API, data and terms unresolved, not declared absent.
6. WFP Egypt food prices on HDX, humanitarian primary dataset, https://data.humdata.org/dataset/wfp-food-prices-for-egypt . Expected update monthly, observed period ends 2026-09-15, dataset metadata update 2026-10-25. High confidence unsuitable for daily village prices; dataset reuse license not visible in extracted page.
7. WFP DataBridges API documentation, first-party developer docs, https://github.com/WFP-VAM/DataBridgesAPI/blob/main/docs/MarketPricesApi.md . Daily/monthly APIs exist but explicit restricted permissions; price flags separate actual/aggregate/estimated/forecasted. High confidence documentation, no assurance daily Egypt coverage or permission granted.
8. Commodities-API latest documentation, vendor docs, https://help.commodities-api.com/article/20-latest-rates-endpoint . Key required, cadence plan-dependent, commodity units include metric ton/cwt/lb. High confidence API exists; not evidence for Egyptian village retail goods. No paid plan recommendation.
9. Al Watan, independent news dated 2024-04-04, https://www.elwatannews.com/news/details/7255597 . Reports Egyptian governmental price monitoring boards and Price Radar work. Corroborating background only, not API access or current coverage proof.
